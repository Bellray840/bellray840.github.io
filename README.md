# Ramsha Art Studio — Easy Editing

## Add your paintings without coding

1. Put your painting photo inside the **images** folder.
2. Open **script.js**.
3. At the very top, edit the `paintings` list.
4. Copy a painting block when you want to add another painting.
5. Make sure the filename exactly matches the image filename.

Example:

```js
{
  image: "my-painting.jpg",
  title: "My Painting",
  status: "Available",
  price: "300 USD (Shipping already included)",
  size: "12 × 18 inches",
  medium: "Acrylic on canvas",
  description: ""
}
```

You can keep all your original high-resolution photos on your computer and upload them directly to the GitHub `images` folder. You do NOT need to send them to ChatGPT.

## Contact links

The WhatsApp, Instagram, Email and Mailing List links currently contain placeholders. Replace those later with your real links.

## GitHub Pages

Upload the files to a GitHub repository. Then go to Settings → Pages → Deploy from a branch → main → /(root) → Save.

The `index.html` file must stay in the main/root folder.
